# Vibe Tree v0.7.3 发布文案草案

目标版本：`v0.7.3`。

这是 `v0.7.2` 之后的补丁版，主要修复大型本地 Codex 数据目录下的启动卡顿，并修复成就导航角标被相邻标签遮挡的问题。

这份文档分成两部分：

- App 内更新公告：来自 `updates/manifest.json`，给普通用户快速理解本次更新。
- GitHub Release Notes：正常 release 记录，给想了解完整版本变化的用户和开发者看。

## App 内更新公告

App 内公告不直接展示完整 GitHub Release body，而是读取 `updates/manifest.json` 里对应版本的结构化内容。

当前 `updates/manifest.json` 中的短公告大致如下：

```text
Vibe Tree v0.7.3

本次更新是 v0.7.2 之后的稳定性补丁：启动时读取大型 Codex 会话目录更平滑，补扫用量时不会反复刷新整个界面；成就页的新成就角标也会浮在导航上方，不再被相邻标签遮住。

主要变化
- Codex 会话扫描改成分片执行，读取大型本地会话目录时不应该再长时间卡住主进程。
- 本地补扫新 Token 时会合并界面刷新，减少启动后短时间内的 CPU 峰值。
- 数据来源开关现在也会控制对应监听器；关闭某个来源后，它不会继续在后台扫描。
- 成就页的新成就角标保持浮出显示，并且不会再被“排行榜”等相邻标签遮住。

体验改进
- 修复大型 Codex 本地数据目录下，启动 Vibe Tree 可能让电脑明显卡顿的问题。
- 修复补扫多条用量记录时，主进程逐条查重并逐条广播完整数据导致界面反复重算的问题。
- 修复禁用来源后，后台监听器仍可能继续扫描该来源的问题。
- 修复成就导航角标被相邻标签遮挡的问题。
```

## GitHub Release Notes

```md
# Vibe Tree v0.7.3

## Fixed

- Fixed startup stalls when Vibe Tree reads large local Codex session folders. Codex scanning now yields in small slices instead of monopolizing the Electron main process.
- Fixed usage backfills repeatedly deduplicating and broadcasting the full ledger for every imported event. Backfilled records now use an ID index and batched UI broadcasts.
- Fixed disabled sources still being scanned by background watchers. Source toggles now also control watcher startup.
- Fixed the achievement tab's new-achievement badge being covered by adjacent navigation tabs while preserving the floating badge placement.

## Privacy

- No new uploaded fields were added in this release.
- Vibe Tree still does not upload prompts, replies, code files, local paths, or session text.

## Compatibility

- Upgrading from v0.7.2 preserves local data.
- No Worker or D1 migration is required for this patch.
- If you previously disabled sources because startup felt heavy, you can re-enable only the sources you want from Settings.
```
