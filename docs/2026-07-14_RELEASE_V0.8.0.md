# Vibe Tree v0.8.0 发布文案

目标版本：`v0.8.0`。

这是 `v0.7.4` 之后的功能版本，新增 Kimi Code 本地 Token 统计，并修复跨午夜首次启动时可能漏记上一日 Codex 用量的问题。

## GitHub Release Notes

```md
# Vibe Tree v0.8.0

## Added

- Added Kimi Code token tracking from local `~/.kimi-code/sessions/**/wire.jsonl` usage records.
- Added Kimi Code settings, watcher status, source filters, model breakdowns, history charts, and custom session path support.
- Preserved multi-agent Kimi sessions by reporting sub-agent usage under distinct source labels.

## Fixed

- Fixed Codex usage inside the configured history window being skipped when its session file is under the previous calendar-day directory and Vibe Tree first starts after midnight.
- Replayed the Codex watcher state once after upgrade so previously missed in-window usage can be recovered while stable ledger IDs continue to deduplicate existing records.

## Privacy

- Kimi Code session records are read locally. Prompts, replies, code files, local paths, and session text are not uploaded.
- No uploaded fields were added. When multi-device sync is enabled, Kimi Code uses the existing token, source, and model aggregate fields.

## Compatibility

- No Worker or D1 migration is required.
- Existing local ledger data remains compatible. The Codex watcher state is rebuilt once during upgrade.
```
