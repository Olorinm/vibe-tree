# Vibe Tree v0.8.1 发布文案

目标版本：`v0.8.1`。

这是 `v0.8.0` 之后的补丁版本，修复 macOS 命令行启动时菜单栏身份不稳定的问题，取消等级上限，并暂时下线尚未准备好的社交入口。

## App 内更新公告

### Vibe Tree v0.8.1

macOS 菜单栏小树现在使用稳定的 Vibe Tree 应用身份运行；等级成长不再封顶。

#### 更新内容

- 修复 macOS 命令行启动仍沿用通用 Electron 身份的问题。
- macOS 会生成本地 `Vibe Tree.app`，Dock 和菜单栏不再显示为通用 Electron 应用。
- 沿用原有本机小树和统计数据，不需要 Apple Developer 账号。
- 等级可以继续成长，不再停在原有最高等级。
- 社交页暂时下线；好友和群组数据不会删除，排行榜、同养小树和云同步继续可用。

#### 隐私

- 本次更新不改变上传内容。

## GitHub Release Notes

```md
# Vibe Tree v0.8.1

## Changed

- Removed the Vibe Tree level cap so growth can continue beyond the previous maximum level.
- Temporarily withdrew the Social page while preserving existing friend and group data.
- Leaderboards, shared trees, and cloud sync remain available.
- Updated the Electron runtime so macOS can preserve the menu bar item's identity across launches.

## Fixed

- Fixed macOS command-line startup continuing to use the generic Electron identity.
- `npm start` now builds and launches a local `Vibe Tree.app` with a stable application identity for the menu bar and Dock.
- Existing command-line user data is automatically reused by the local app.
- In-app updates now restart through the new Vibe Tree app identity after installation.

## Privacy

- This release does not change uploaded fields or data categories.

## Compatibility

- The local macOS app uses ad-hoc signing and does not require an Apple Developer account.
- Windows startup behavior is unchanged.
- No Worker or D1 migration is required.
```
